## 🚀 YTdownloader

**YTdownloader** is a free YouTube video downloader built with **Python** and **yt-dlp**.

The project was created as part of my journey learning Python and software development. The goal is simple: paste a YouTube video URL and let the program handle the downloading process.

> ⚠️ **Please download only content that you have permission to download. Respect copyright laws, content creators, and YouTube's Terms of Service.**

## 🎯 How Does It Work?

The process is simple:

```text
        ┌─────────────────┐
        │  YouTube URL 🔗 │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │     Python 🐍   │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │     yt-dlp ⚡   │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │ Analyze Video 🔎│
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │   Download 📥   │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │  Local File 📁  │
        └─────────────────┘
```

### 🔍 Behind the Scenes

1. You provide a YouTube URL.
2. Python receives the URL.
3. Python passes the URL to `yt-dlp`.
4. `yt-dlp` analyzes the available media.
5. The selected media is downloaded.
6. The file is saved locally.

## 📋 Requirements

Before running YTdownloader, make sure you have:

* 🐍 **Python 3.10+**
* 📦 **yt-dlp**
* 🟢 **Deno or Node.js** when required for YouTube JavaScript challenge/signature solving
* 🌐 An active internet connection

## ⚙️ Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/thelewi/YTdownloader.git
cd YTdownloader
```

### 2️⃣ Install yt-dlp

```bash
python -m pip install -U yt-dlp
```

### 3️⃣ Run the program

If the main Python file is called `main.py`:

```bash
python main.py
```

If your Python file has another name, replace `main.py` with the correct filename.
